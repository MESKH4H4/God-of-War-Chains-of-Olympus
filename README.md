# God of War: Chains of Olympus HD Texture Pack

God of War: Chains of Olympus HD Texture Pack (PPSSPP)

This is a complete HD texture pack for God of War: Chains of Olympus (PSP), developed for the PPSSPP emulator.

**Key difference from normal upscales:** Instead of directly upscaling the original PSP textures, I used textures extracted from the **PS3 version** (God of War Collection – Chains of Olympus) and applied the upscale to those images. This gives a much better base quality before AI processing.

Out of 928 textures used in the pack, only 28 came from the original PSP dump with upscaling, because they either had no equivalent in the PS3 version or couldn't be extracted properly.

# Project Features

- **AI-Powered Upscaling**  
  All main textures were processed using the HDCube4Plus AI model.

- **Source from PS3 Version**  
  Textures were extracted from the PS3 remaster of God of War: Chains of Olympus, which already provides higher resolution artwork compared to the PSP original. These were then upscaled 4x for maximum quality.

- **Folder Structure**  
  The folders inside the pack are named exactly as they were extracted from the PS3 version.
  
# Pack Versions

The pack is available in four different versions.

## PNG (Best Quality)

PNG preserves the highest quality textures, but has a greater impact on performance.

- **PNG Normal**
- **PNG Vibrant Colors**

Each version is between 750 and 850 MB. Every version is provided as a **single .rar file** – no splitting required, as each one fits well within GitHub’s 2GB limit.

## KTX2 (Better Performance)

KTX2 is a compressed format optimized for emulation.

- **KTX2 Normal**
- **KTX2 Vibrant Colors**

These versions include:

- Better performance
- Faster loading
- Smaller file size (600 MB)

The visual difference compared to PNG is minimal in most cases. Therefore, I recommend using KTX2. If your PC is powerful, you can go with PNG, but if it's a bit weaker, use KTX2. The visual difference is so minimal that you won't even notice it, and it will run much better..

# Difference from the "Vibrant Colors" Version

The Vibrant Colors version uses color processing that slightly increases the vibrancy and chromatic fidelity of the images.

This process was done by converting color profiles using AdobeRGB → sRGB, preserving transparency and applying maximum PNG compression.

The goal is to produce slightly more vibrant colors without distorting the original artwork.

# Installation

1. Copy the UCES00842 folder to your \Textures folder
2. Enable texture replacements in the developer tools
3. Done!
